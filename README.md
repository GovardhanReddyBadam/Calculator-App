# 🧮 Modern Calculator App

A modern and responsive Calculator Application built using **HTML, CSS, and JavaScript** with support for:

* basic arithmetic operations
* scientific calculations
* keyboard input
* dark/light mode
* calculation history
* responsive UI
* interactive animations

This project was built to practice real-world frontend development concepts such as:

* DOM Manipulation
* Event Handling
* JavaScript Logic
* CSS Grid
* State Management
* Responsive Design

---

# 🚀 Features

## ✅ Basic Calculator Features

* Addition
* Subtraction
* Multiplication
* Division
* Percentage
* Decimal Support

---

## ⌨️ Keyboard Support

Supports:

* Number keys
* Operators (`+ - * / %`)
* `Enter` → Calculate
* `Backspace` → Delete
* `Escape` → Clear

---

## 🧠 Scientific Operations

Includes:

* Square Root
* Power (`x²`)
* Sine (`sin`)
* Cosine (`cos`)
* Tangent (`tan`)
* Logarithm (`log`)

---

## 🌙 Theme Switcher

* Dark Mode
* Light Mode
* Smooth Theme Transition

## 📜 Calculation History

* Stores previous calculations
